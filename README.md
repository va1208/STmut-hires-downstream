# STmut CNV Clustering and CDT Reordering Workflow

This repository contains an R-based workflow for organizing STmut
copy-number variation (CNV) output by cluster similarity and generating
a reordered CNV heatmap.

The workflow consists of three main steps:

1.  Run **STmut** and collect the required output files.
2.  Cluster the STmut CNV profiles using `cnv_cdt_clustering_updated.R`.
3.  Define the desired cluster order in `ordering_cluster.txt` and use
    `reorder_cdt_file_hires.R` to reorder the samples and generate the
    final heatmap.

------------------------------------------------------------------------

## Workflow overview

``` text
STmut
  |
  |-- CNV CDT file
  |-- BarcodeLegend file
  |-- cluster assignment file
  |-- cluster annotation file
  |
  v
cnv_cdt_clustering_updated.R
  |
  |-- cluster_dendrogram.pdf
  |-- cluster_analysis_objects.RDS
  |
  v
Inspect dendrogram and define biological/desired cluster order
  |
  |-- ordering_cluster.txt
  |
  v
reorder_cdt_file_hires.R
  |
  |-- <prefix>_tumorclones_projection.csv
  |-- <prefix>_reordered_heatmap.png
  |
  `-- optionally: <prefix>_reordered.cdt
      (enable the fwrite line in the script)
```

------------------------------------------------------------------------

# Step 1 --- Run STmut

Run STmut using the appropriate inputs for your spatial transcriptomics
dataset.

After STmut completes, retain the files needed for the downstream
clustering and reordering steps.

## Required files

### 1. CNV CDT file

Example:

``` text
CNVs_OrganizedByGEcluster_UMIcount.cdt
```

The CDT file contains the CNV profiles. The barcode/spot identifiers are
represented as columns.

### 2. Barcode legend

Example:

``` text
cluster_barcode_summary.csv
```

This file is used by `reorder_cdt_file_hires.R`.

### 3. Cluster assignment file

This is the cluster file  used for STmut/clustering.

Conceptually:

``` text
Barcode,Cluster
AAACAAGTATCTCCCA-1,Cluster 1
AAACACCAATAACTGC-1,Cluster 1
AAACAGAGCGACTCCT-1,Cluster 2
AAACAGCTTTCAGAAG-1,Cluster 2
```


### 4. Cluster annotation file

The reordering script requires a cluster annotation table containing:

``` csv file
cluster,annotate
cluster1,tumor
cluster2,tumor
cluster3,normal
```

The `annotate` values are used to organize the final heatmap and
tumor/normal annotation.

# Step 2 --- Cluster CNV profiles

Run:

``` text
cnv_cdt_clustering_updated.R
```

## Purpose

The script:

-   finds barcodes shared between the STmut CDT file and cluster
    assignment file;
-   calculates the average CNV profile for each cluster;
-   calculates Euclidean distances between cluster-level CNV profiles;
-   performs hierarchical clustering using `ward.D2`;
-   generates a dendrogram showing CNV similarity among clusters; and
-   saves the clustering objects for downstream inspection.

## Required R packages

``` r
install.packages(c(
    "data.table",
    "ggplot2"
))
```

## Usage

``` bash
Rscript cnv_cdt_clustering_updated.R \
    <STmut_CDT_file> \
    <cluster_assignment_file> \
    <output_directory>
```

Example:

``` bash
Rscript cnv_cdt_clustering_updated.R \
    CNVs_OrganizedByGEcluster_UMIcount.cdt \
    cluster_info.txt \
    cnv_cluster_analysis
```

## Arguments

  Position    Input              Description
  ----------- ------------------ ------------------------------------
  `args[1]`   CDT file           CNV CDT file generated by STmut
  `args[2]`   Cluster file       Barcode-to-cluster assignment file
  `args[3]`   Output directory   Directory for clustering results

## Outputs

The output directory contains:

``` text
cnv_cluster_analysis/
├── cluster_dendrogram.pdf
└── cluster_analysis_objects.RDS
```

### `cluster_dendrogram.pdf`

Hierarchical clustering of the average CNV profiles for the clusters.

Use this plot to identify clusters with similar CNV patterns and
determine an appropriate ordering for the final heatmap.

### `cluster_analysis_objects.RDS`

Contains:

``` r
cluster_matrix
distance_matrix
hc
```

You can inspect it in R:

``` r
x <- readRDS("cnv_cluster_analysis/cluster_analysis_objects.RDS")

x$cluster_matrix
x$distance_matrix
x$hc
```

To obtain the dendrogram leaf order programmatically:

``` r
x <- readRDS("cnv_cluster_analysis/cluster_analysis_objects.RDS")

cluster_order <- x$hc$labels[x$hc$order]

cluster_order
```

For example, the result might be:

``` text
Cluster4
Cluster5
Cluster6
Cluster10
Cluster12
Cluster13
Cluster14
Cluster17
Cluster8
Cluster3
Cluster7
Cluster9
Cluster16
Cluster19
Cluster20
Cluster21
Cluster22
Cluster23
```

The exact order will depend on your dataset.

> **Important:** inspect the dendrogram and biological annotations
> before choosing the final ordering. The dendrogram leaf order can
> provide a starting point, but the final ordering file can be adjusted
> to group biologically meaningful tumor clones or normal clusters.

# Step 3 --- Create `ordering_cluster.txt`

Create a tab-delimited text file called:

``` text
ordering_cluster.txt
```

The file must:

-   contain **no header**;
-   contain **two columns**;
-   use a **tab** between the columns;
-   list clusters in the exact order desired in the final heatmap;
-   use the first column for cluster name/number; and
-   use the second column for the annotation/group used in the heatmap.

## Example

``` text
Cluster4    tumor1
Cluster5    tumor1
Cluster6    tumor1
Cluster10   tumor2
Cluster12   tumor2
Cluster13   tumor2
Cluster14   tumor3
Cluster17   tumor3
Cluster8    tumor4
Cluster3    tumor4
Cluster7    tumor5
Cluster9    tumor5
Cluster16   tumor6
Cluster19   tumor6
Cluster20   tumor7
Cluster21   tumor7
Cluster22   normal
Cluster23   normal
```

The annotation names above are examples only. Replace them with the
annotations appropriate for your sample.

The order of rows controls the cluster order in the final heatmap. The
order in which annotation groups first appear also determines the
annotation-group ordering used by the script.

# Step 4 --- Reorder the CDT and generate the heatmap

Run:

``` text
reorder_cdt_file_hires.R
```

## Required R packages

The script uses:

``` r
optparse
data.table
ggplot2
dplyr
ComplexHeatmap
circlize
```

For example:

``` r
install.packages(c(
    "optparse",
    "data.table",
    "ggplot2",
    "dplyr",
    "circlize"
))

if (!requireNamespace("BiocManager", quietly = TRUE))
    install.packages("BiocManager")

BiocManager::install("ComplexHeatmap")
```

## Usage

``` bash
Rscript reorder_cdt_file_hires.R \
    -i <STmut_CDT_file> \
    -l <BarcodeLegend_file> \
    -g <cluster_assignment_file> \
    -a <cluster_annotation_file> \
    -c <ordering_cluster.txt> \
    -o <output_prefix>
```

Example:

``` bash
Rscript reorder_cdt_file_hires.R \
    -i CNVs_OrganizedByGEcluster_UMIcount.cdt \
    -l BarcodeLegend.csv \
    -g cluster_info.txt \
    -a cluster_annotation.txt \
    -c ordering_cluster.txt \
    -o sample01
```

## Arguments

  -----------------------------------------------------------------------
  Option                              Description
  ----------------------------------- -----------------------------------
  `-i`, `--cdt_file`                  STmut CNV CDT file

  `-l`, `--barlegend`                 Barcode legend generated by STmut

  `-g`, `--cluster_info`              Barcode-to-cluster assignment file

  `-a`, `--annotate`                  Cluster annotation file

  `-c`, `--order_cluster`             Tab-delimited cluster ordering file
                                      with no header

  `-o`, `--output`                    Output filename prefix
  -----------------------------------------------------------------------

## Current outputs

For an output prefix of:

``` text
sample01
```

the current script generates:

``` text
sample01_tumorclones_projection.csv
sample01_reordered_heatmap.png
```

### Tumor clone projection

``` text
sample01_tumorclones_projection.csv
```

This file expands the merged barcode information and associates the
component barcodes with the ordered annotation/tumor-clone groups.

### Reordered CNV heatmap

``` text
sample01_reordered_heatmap.png
```

The heatmap:

-   preserves the requested cluster ordering;
-   does not re-cluster rows or columns;
-   separates columns by the annotation supplied in
    `ordering_cluster.txt`;
-   displays chromosome strips along the rows; and
-   uses blue/white/red coloring for lower/neutral/higher CNV signal.

# Notes

-   Barcode names in the CDT file, barcode legend, and cluster
    assignment file must be consistent.
-   Cluster names should contain a numeric cluster identifier such as
    `Cluster 4` or `cluster 4`; the reordering script extracts the
    trailing cluster number.
-   Every barcode used in the barcode legend must receive a valid
    annotation after merging with the cluster information. The script
    stops if annotation values are missing.
-   Clusters not explicitly included in `ordering_cluster.txt` are
    appended after the requested clusters in numeric order.
-   The current heatmap output is a 5000 × 5000 pixel PNG at 290 dpi.
-   Before running Step 2, check the final `message()` call in
    `cnv_cdt_clustering_updated.R`. In the uploaded version, the closing
    parenthesis appears to be missing. It should be:

``` r
message("Cluster analysis objects saved in the output folder.")
```
